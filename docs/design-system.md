# AI 家谱编辑系统 — 前端设计规范

| 项 | 内容 |
|---|---|
| 版本 | v1.1（2026-10-22，2.6.3 + 1.7.3） |
| 技术基线 | React 18 + TypeScript + Vite 6 + Ant Design 5 + TanStack Query 5 |
| 令牌来源 | `web/src/theme/tokens.ts`、`web/src/theme/index.ts`、`web/src/styles/global.css` |
| 适用范围 | `web/` 全部页面、组件与后续工作包 |

本文件定义前端视觉与交互基线。业务页面在后续工作包实现时，必须沿用本文件的色彩、排版、布局与高风险交互约束；新增令牌先更新本文件与 `tokens.ts`，不得在页面内散落硬编码颜色。

## 1. 设计原则

1. **纸墨气质，克制装饰**：以宣纸底色、墨青主色、朱砂印章色建立家谱场景识别，不使用渐变、玻璃拟态或大面积阴影。
2. **信息优先**：家谱数据以姓名、世代、生卒、来源为主；装饰不得压过数据与校验状态。
3. **隐私可见**：遮罩不是隐藏问题的手段。VIEWER 视角必须显示“在世人物信息已按隐私规则遮罩”的说明。
4. **风险可感知**：合并、删除、接受草稿、确认叙事、导出、标记已故等高风险动作必须二次确认并展示影响摘要，不提供“不再提示”。
5. **AI 与事实分离**：AI 结果使用“草稿/建议”视觉语义，不得与已确认事实混淆；Mock 模式必须显式标识。

## 2. 色彩

| 令牌 | 色值 | 用途 |
|---|---|---|
| `colorPrimary` | `#2F5D57` 墨青 | 主按钮、选中态、链接、品牌色 |
| `colorSeal` | `#A6442F` 朱砂 | 品牌印章、少量强调，不用于大面积背景 |
| `colorPaper` | `#F5F2EA` 宣纸 | 页面背景 |
| `colorSurface` | `#FFFFFF` | 卡片、侧栏、页头 |
| `colorText` | `#262626` | 主要文本 |
| `colorTextSecondary` | `#5C5C5C` | 辅助说明、次要信息 |
| `colorBorder` | `#DED7C9` | 分隔线、边框 |
| `colorSuccess` | `#3D7A57` | 校验通过、服务正常 |
| `colorWarning` | `#B7791F` | 警告问题、待确认 |
| `colorError` | `#B23A34` | 错误、危险操作 |
| `colorSelectedBg` | `#E7EFEC` | 菜单选中背景 |

规则：

- 正文不得使用低于 `#5C5C5C` 的灰色；禁用状态除外。
- 红色只用于错误、危险操作与朱砂品牌点缀，不用作普通装饰。
- 状态不能只靠颜色区分，必须同时提供文字或图标。

## 3. 字体与排版

- 正文：系统中文无衬线字体栈（PingFang SC / 微软雅黑 / Segoe UI），不加载外部字体或 CDN。
- 品牌、页面标题：宋体系统字体栈（Songti SC / STSong / SimSun），仅用于品牌与标题，正文不使用。
- 基础字号 14px；页面标题 18px；卡片标题 16px；辅助文字 12–13px。
- 行高：正文 1.6；标题 1.3；不使用全大写英文作为中文界面标题。
- 日期、版本号、置信度等数字使用等宽或表格数字对齐（后续表格包实现）。

## 4. 布局

| 项 | 值 |
|---|---|
| 侧栏展开宽度 | 240px |
| 侧栏收起宽度 | 72px |
| 页头高度 | 64px |
| 内容区内边距 | 24px（≤768px 时 16px） |
| 内容最大宽度 | 1440px，居中 |
| 卡片圆角 | 12px |
| 控件圆角 | 8px |

- 桌面优先，最小可用宽度 1024px；≤768px 时压缩内边距并隐藏品牌副标题。
- 页面结构：左侧导航 + 顶部页头（当前页标题、服务状态）+ 内容区 + 页脚。
- 页面内容使用单一主卡片或表格，不堆叠多层卡片。
- 侧栏分组顺序：概览 → 档案 → 智能处理 → 质量与查询 → 协作与审计 → 系统。

## 6. 组件与交互约定

### 6.1 反馈

- API 错误统一显示稳定错误码对应的中文提示与 `requestId`（便于排查），保留用户已填内容。
- 表单错误显示在字段下方；提交失败不得清空表单。
- 加载态使用骨架屏或局部 `Spin`，不使用全屏遮罩阻塞导航。
- 空态必须说明“为什么为空”和“下一步做什么”，不使用只有插图的空白页。

### 6.2 高风险操作

- 合并人物、删除人物/关系、接受草稿、批量接受、确认叙事、导出、标记已故：必须弹出二次确认，列出影响人数/关系数/引用数/遮罩范围。
- 409 冲突：展示差异与“刷新/重新预览”入口，不自动重试、不自动覆盖。
- 审核相关操作显示版本号与审批理由必填提示。

### 6.3 AI 与隐私

- 任何页面不得使用 `dangerouslySetInnerHTML` 渲染模型输出；AI 文本以纯文本 + 组件展示。
- AI 草稿使用“草稿”标签与低置信提示；Mock 提供方显示“Mock（无外部调用）”。
- VIEWER 页面固定显示遮罩说明；遮罩字段保持布局稳定，不因脱敏出现跳动。
- API Key 不得出现在前端代码、环境变量示例或任何界面。

### 6.4 表格与表单（后续页面复用）

- 表格默认分页 20 条，支持空态、错误态与加载态；操作列按角色隐藏。
- 日期使用部分日期组件，未知月/日显示为“—”，不得补全。
- 所有写操作携带 `version`；成功后刷新详情，失败保留输入。

### 6.5 审计页面与认证状态

- 审计日志是只读页面：顶部固定显示“只读”标签与 L3 说明（IP、User-Agent、密码哈希、令牌、服务器路径不返回前端），不提供修改、删除或导出入口。
- 失败动作使用红色“失败”标签，不能只靠颜色区分；脱敏快照统一显示 `[已隐藏]`，并在详情中提示“部分字段已隐藏”。
- 详情使用抽屉（桌面宽度 640px）：先差异表、后完整快照；快照为纯文本 `<pre>`，不使用 `dangerouslySetInnerHTML`。
- 权限与遮罩说明使用独立抽屉（560px），以表格呈现四角色矩阵，并注明审核中心联动与受控导出尚未开放。
- 页头展示当前用户显示名与角色标签，提供“退出”按钮；≤768px 时隐藏姓名，仅保留角色与退出。
- 登录页为布局外独立卡片，错误在卡片内展示；仅接受站内 `redirect`，拒绝 `//` 与 `/\` 形式的外部跳转。

## 7. 无障碍与键盘

- 交互控件必须有可见焦点样式，禁止 `outline: none`。
- 图标按钮必须有 `aria-label`（如侧栏折叠按钮）。
- 颜色对比度满足 WCAG AA；正文与背景对比度不低于 4.5:1。
- 对话框打开后焦点进入对话框，关闭后回到触发元素（AntD 默认行为，后续不得覆盖）。
- 错误结果页使用 `role="alert"`，便于读屏软件播报。

## 8. 实现约束

- 主题唯一入口：`ConfigProvider locale={zhCN} theme={appTheme}`；不得在页面中另建 `ConfigProvider` 覆盖全局令牌。
- 全局 CSS 只放布局与基础样式；组件样式优先使用 AntD 令牌与组件属性。
- `global.css` 中的 CSS 变量与 `tokens.ts` 必须保持同值；修改颜色时同步两处与本文件。
- 不引入外部字体、图标 CDN 或运行时样式服务；图标统一使用 `@ant-design/icons`。
- 新增依赖需经工作包授权；1.1.1 不包含 Zustand、React Flow、dagre、html-to-image。
